# 02 · 原型说明与交互标注

> 作业要求里的「动态面板、母版、展开折叠节点、导航」都是 Axure RP 的术语。
> 本项目用可运行的代码实现，下面逐项说明**每个概念对应到哪一段实现**，方便对照评分。

## 一、动态面板（Axure Dynamic Panel）

**通用组件**：`static/js/core.js → class Panel`

```html
<div data-panel data-mode="fade">          <!-- fade：淡入淡出；slide：横向滑动 -->
  <div data-state>状态一</div>
  <div data-state>状态二</div>
</div>
<div class="panel-tabs">
  <button data-goto="0" aria-selected="true">状态一</button>
  <button data-goto="1" aria-selected="false">状态二</button>
</div>
```

特性：同一时刻只显示一个状态；切换器可以放在面板内，也可以放在面板外（全局事件委托会向上找到最近的面板）。

| 出现位置 | 状态 | 模式 |
| --- | --- | --- |
| Web 盲盒详情 | 图文详情 / 取餐须知 / 同学评价 | fade |
| App 盲盒详情 | 里边有什么 / 取餐须知 / 评价 | slide（横向滑动） |
| Web 我的订单 | 待取餐 / 已取餐 / 已取消 | fade |
| App 我的订单 | 待取餐 / 已取餐 / 已取消 | fade |
| Web 碳账户 | 可兑换 / 我的权益 | fade |
| App 碳账户 | 积分流水 / 减碳榜 / 去兑换 | slide |
| 后台经营概览 | 按日 / 按周 / 按月（切换时重新拉取数据重绘图表） | fade |
| 后台新建盲盒 | 1 基本信息 → 2 库存与时段 → 3 确认发布 | slide |

## 二、母版（Axure Master）

**注册表**：`static/js/core.js → Master`，用 `Master.define(name, render)` 定义、`Master.render(name, ctx)` 取用。
改一处，三端同时生效——这就是母版的意义。

| 母版名 | 复用范围 |
| --- | --- |
| `web-topbar` | Web 学生端全部 5 页（导航 + 校区切换 + 登录态） |
| `web-footer` | Web 学生端全部 5 页 |
| `box-card` | Web 首页、盲盒广场 |
| `code-card` | Web 我的订单、Web 详情说明 |
| `app-tabbar` | App 端 4 个主 Tab 页（首页 / 订单 / 碳账户 / 我的） |
| `app-nav` | App 端所有二级页（标题 + 返回 + 右侧动作） |
| `app-box-row` | App 首页列表、搜索结果 |
| `side` | 后台全部 6 页（侧边导航，含折叠分组） |
| `admin-topbar` | 后台全部 6 页（面包屑 + 账号） |
| Toast / Modal / 空状态 | 三端共用，`toast()`、`modal()`、`empty()` |

## 三、展开折叠节点

**组件**：`bindTree(root, opts)`（树，可多级、可带操作按钮）、`bindAccordion(root)`（手风琴）。

| 位置 | 形态 | 行为 |
| --- | --- | --- |
| Web 盲盒广场 · 按餐段 | 二级树 | 点餐段展开/收起品类；选中即筛选，再点一次取消 |
| 后台 · 分类与菜品 | 二级树 | 展开折叠 + 行内「加子项 / 改名 / 删除」，删除有二次确认 |
| 后台 · 侧边导航 「盲盒管理」 | 折叠分组 | 点标题展开/收起「盲盒列表 / 新建盲盒」，不跳转 |
| App · 我的 → 帮助中心 | 手风琴 | 按组展开问题，答案随展开显示 |
| App · 我的 → 我的权益 | 折叠面板 | 点击「我的权益」展开已兑换列表 |

## 四、导航

| 端 | 导航形式 | 说明 |
| --- | --- | --- |
| Web 学生端 | 顶部主导航 + 校区切换器 + 面包屑 | hash 路由（`#/square`、`#/box/1`…），导航项高亮当前页 |
| App 端 | 底部 4 Tab + 顶部返回 + 页面栈 | Tab 页之间平级跳转，详情/确认页压栈，`‹` 返回上一页 |
| 商家后台 | 左侧固定导航 + 顶栏面包屑 | 侧栏一级直跳、二级折叠，顶栏显示当前位置 |
| 全局 | 项目首页 `/` → 三个端互跳 | 一次登录态跨端复用（学生端与后台是不同角色） |

## 五、逐页交互标注

### Web 学生端

**首页 `#/`**
- 顶部数字实时按「当前校区」统计：今日余量份数、平均折扣、今日可减碳（千克）。
- 「看看今天有什么」→ 跳盲盒广场；「它怎么运作」→ 平滑滚动到三栏说明。
- 卡片任意位置点击 → 详情；售罄卡片置灰且不可点。
- 底部常见问题取帮助中心前两组各 2 条，手风琴展开。

**盲盒广场 `#/square`**
- 左侧餐段树筛选 + 「只看有货 / 价格低到高 / 余量多到少」三个 chip + 关键词搜索。
- 任意条件组合生效；无结果显示空状态并给出「清空筛选」。
- 顶部切换校区会重新拉取该校区全部盲盒。

**盲盒详情 `#/box/:id`**
- 数量步进器 1–5，上限取「5 与剩余份数」的较小值；合计金额联动。
- 「立即预订」→ 弹出确认框（档口、时段、份数、应付、预计减碳）→ 确认后跳订单页。
- 未登录时点预订直接弹出登录框。

**我的订单 `#/orders`**
- 三个 Tab 用动态面板切换，Tab 上带各自数量。
- 待取餐订单展示大号核销码；「取消订单」二次确认后份数退回。
- 已取餐订单展示获得的碳积分；「再订一次」跳对应盲盒详情。

**碳账户 `#/carbon`**
- 顶部深色区域：成长树 SVG（随等级增加树冠与果实）+ 累计积分 + 等级进度条 + 四项统计。
- 中部两栏：积分流水（正为绿、负为红）、校内减碳榜（当前用户高亮）。
- 底部动态面板：可兑换 / 我的权益；兑换需二次确认，积分不足时按钮禁用。

### App 手机端

**登录 `#/login`** — 手机号 11 位校验；任意号码自动注册学生账号；校区下拉。
**首页 `#/home`** — 问候语按时段变化；校区切换；餐段 pill 横向滚动筛选；余量横幅；卡片列表。
**详情 `#/box/:id`** — 底部吸底栏（步进器 + 预订）；三态动态面板滑动切换。
**预订确认 `#/confirm/:id?qty=n`** — 信息核对 + 减碳预估 + 支付按钮（演示环境不真实扣款）。
**订单 `#/orders`** — 三态面板；待取餐显示深色核销码卡与取消按钮。
**碳账户 `#/carbon`** — 三态面板；切到「去兑换」时才懒加载权益列表。
**我的 `#/me`** — 资料卡 + 三项统计；跳转到订单/碳账户；我的权益折叠；帮助中心手风琴；退出登录。

### 商家后台

**经营概览 `#/overview`** — 4 个 KPI + 售出份数（柱）与减碳量（折线）双轴图；
按日/按周/按月切换会重新请求数据并重绘；右侧 Top5 盲盒；下方最近核销记录表。
**盲盒管理 `#/boxes`** — 搜索 / 状态筛选 / 编辑弹窗 / 上下架切换（按钮文案与颜色随状态变化）。
**新建盲盒 `#/boxes-new`** — 三步动态面板，第 3 步实时预览，发布后回列表。
**订单核销 `#/verify`** — 6 位核销码输入框（回车即提交），成功显示绿色结果卡，失败显示红色原因；
右侧今日订单构成；下方订单列表三态切换，点「详情」弹窗。
**分类与菜品 `#/categories`** — 树全部展开；悬停行显示操作按钮；新建餐段 / 加子项 / 改名 / 删除。
**顾客与碳积分 `#/customers`** — 4 个汇总 KPI + 排行榜表格。

## 六、状态与异常

| 场景 | 处理 |
| --- | --- |
| 未登录访问订单 / 碳账户 | 空状态 + 「立即登录」按钮，登录后回到原页 |
| 盲盒售罄 | 封面置灰、卡片标「已售罄」、详情按钮禁用 |
| 份数不足 | toast 提示「仅剩 N 份，请调整数量」 |
| 核销码错误 / 不属于本档口 | 红色结果卡说明具体原因 |
| 重复核销 | 提示「这笔订单已于 X 核销过」 |
| 积分不足兑换 | 按钮禁用并显示「积分不够」 |
| 网络或接口失败 | toast 红色提示，页面不白屏 |

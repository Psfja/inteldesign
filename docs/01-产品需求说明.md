# 01 · 产品需求说明

## 1. 产品一句话

**食光机** —— 闭餐前一小时，把食堂没卖完的热菜做成盲盒，半价卖给学生；
被救下的食物折算成碳积分，记在学生的个人账户里。

## 2. 目标用户与痛点

| 角色 | 是谁 | 痛点 |
| --- | --- | --- |
| 学生（主） | 在校大学生，月生活费有限，对环保有认同感 | 食堂正餐一荤一素 12–18 元，连吃一个月压力大；知道浪费不好，但个人无力改变 |
| 档口 / 食堂（次） | 食堂承包档口、后勤管理处 | 备餐量靠经验估，卖不完只能倒掉；倒掉既是损失也是后勤考核的扣分项 |
| 学校后勤（次） | 后勤集团、团工委 | 缺一个能把"光盘行动"量化、能拿出数据的抓手 |

## 3. 核心价值

1. **省钱**：盲盒价约为原价的 3.5–5 折，一份正餐 4–9 元。
2. **不浪费**：余量餐食在闭餐前被预订带走，直接进入减碳统计。
3. **可量化**：每份盲盒按避免浪费的食物重量估算减碳量，约每 10 克折算 1 碳积分。

## 4. 功能清单

### 4.1 基本功能一：盲盒预订与核销（主流程）

```
学生                                        系统                                  档口
 │                                           │                                     │
 ├─ 浏览今日盲盒（按校区 / 餐段筛选）────────▶│                                     │
 │◀──────────── 盲盒列表 + 剩余份数 + 取餐时段 ┤                                     │
 ├─ 进入详情，选择份数 ─────────────────────▶│                                     │
 ├─ 确认支付 ──────────────────────────────▶│ 校验库存 → 扣减余量 → 生成 6 位核销码 │
 │◀────────────────────────── 订单 + 核销码 ─┤                                     │
 │                                           │                                     │
 ├─ 取餐时段内到窗口出示核销码 ─────────────────────────────────────────▶ 输入核销码 │
 │                                           │◀────────────────────── 提交核销 ─────┤
 │◀── 订单置为已核销，碳积分与减碳量到账 ──────┤                                     │
```

规则：

- 一次最多预订 5 份，不能超过剩余份数；
- 下单即锁份，`remain` 实时扣减，扣到 0 自动转为「已售罄」；
- 取消订单会把份数退回盲盒池，售罄状态自动恢复为在售；
- 错过取餐时段订单自动失效，费用原路退回，不产生减碳记录也不扣积分；
- 核销码 6 位数字，商家只能核销自己档口的订单（平台运营账号可核销全部）。

### 4.2 基本功能二：碳积分账户

- 每完成一次取餐，按 `碳减排克数 ÷ 10` 发放积分，写入流水；
- 累计积分决定等级：一粒米 → 小嫩芽 → 青苗 → 小树 → 大树 → 一片林，
  碳账户首页有一棵**随等级生长的树**作为唯一的视觉记忆点；
- 校内减碳排行榜按累计积分排序，当前用户高亮；
- 积分可兑换食堂代金券、豆浆券、环保餐具、文创勋章等权益，兑换后生成使用码。

### 4.3 商家侧功能

- 经营概览：订单数、售出份数、减碳量、余量售出率四个 KPI + 售出/减碳双轴趋势图（日/周/月切换）
- 盲盒管理：列表筛选、编辑改价改量、上架 / 下架、三步向导新建盲盒
- 订单核销：输入核销码即时验证 + 订单列表（全部 / 待取餐 / 已核销）+ 订单详情
- 分类与菜品：餐段 → 品类两级分类树，可展开折叠、增改删
- 顾客与碳积分：排行榜与减碳汇总

## 5. 信息架构

```
食光机
├── 学生端（Web / App）
│   ├── 首页（今日余量、餐段筛选、盲盒列表）
│   ├── 盲盒详情（图文 / 取餐须知 / 评价）
│   ├── 预订确认（份数、金额、减碳预估）
│   ├── 我的订单（待取餐 / 已取餐 / 已取消，核销码）
│   ├── 碳账户（成长树、流水、排行榜、兑换）
│   └── 我的（资料、我的权益、帮助中心）
└── 商家端（Web 后台）
    ├── 经营概览
    ├── 盲盒管理 / 新建盲盒
    ├── 订单核销
    ├── 分类与菜品
    └── 顾客与碳积分
```

## 6. 设计语言

| 维度 | 选择 | 来源 |
| --- | --- | --- |
| 主色 | 墨绿 `#12231C` / 苔绿 `#2F6B4F` | 食堂菜单黑板 |
| 强调色 | 餐票黄 `#F2C230`（碳积分） | 打饭小票 |
| 警示色 | 番茄红 `#D9432B`（售罄、实付价） | 剩食警示 |
| 底色 | 纸白 `#FBF8F1` | 小票纸 |
| 标题 / 数字 | 宋体（`Songti SC` 等） | 食堂菜单的书写感 |
| 正文 | 黑体（苹方 / 鸿蒙 / 微软雅黑） | 屏幕阅读 |
| 等宽 | 只用于核销码、订单号 | 功能性，不作装饰 |

原则：颜色只传递状态（有货 / 紧张 / 售罄），装饰让位给信息；
全局只有一个视觉记忆点——碳账户里那棵随积分长大的树。

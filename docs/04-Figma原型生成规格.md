## 3. 设计系统（Design Tokens）

### 3.1 色彩

全部建成 Figma Color Variables。

| 变量名 | HEX | 用途 |
| --- | --- | --- |
| `ink` | `#12231C` | 主文字、深色底（顶栏选中、核销码卡、后台侧栏、深色 KPI） |
| `ink-2` | `#1C3B2F` | 主按钮 hover |
| `moss` | `#2F6B4F` | **主色**：主按钮、减碳数字、选中态 |
| `moss-deep` | `#24503C` | 主按钮 hover、选中文字 |
| `moss-soft` | `#E7EFE7` | Tag 底色、选中胶囊底、成功提示底 |
| `butter` | `#F2C230` | **强调色**：碳积分、手写下划线、强调数字 |
| `butter-deep` | `#D9A413` | 图表折线、星级、积分价格 |
| `butter-soft` | `#FBF1D3` | 折扣 Tag 底、权益图标底 |
| `tomato` | `#D9432B` | **警示 + 实付价**：售罄、价格、取消、角标 |
| `tomato-soft` | `#FBE9E5` | 错误/警示 Tag 底 |
| `paper` | `#FBF8F1` | 页面底色（不是纯白） |
| `card` | `#FFFFFF` | 卡片、输入框、浮层 |
| `line` | `#E2DCCD` | 分隔线、边框、图表网格 |
| `line-strong` | `#CBC3AE` | 表头下划线、幽灵按钮边框 |
| `muted` | `#6E7A6F` | 次要文字、标签说明 |
| `muted-2` | `#93A094` | 三级文字、原价删除线、图表轴标签 |

**颜色使用铁律**
- 绿色 = 正常 / 减碳 / 成功；黄色 = 碳积分 / 折扣；红色 = 售罄 / 实付价 / 危险操作
- 页面底永远用 `paper`，卡片用 `card`，**不要大面积纯白背景**
- 不要使用渐变作为装饰，渐变只允许出现在"盲盒封面底"这一处（`linear-gradient(160deg, #F4EFE3, #E9E2D1)`）

### 3.2 字体

建立 3 个 Text Style 族。

| 样式名 | 字族 | 用途 |
| --- | --- | --- |
| `Display/数字与标题` | `Songti SC`, `Noto Serif SC`, `Source Han Serif SC`, `STSong`, Georgia, serif | H1/H2/H3、所有大数字（KPI、价格、积分、排名） |
| `Body/正文` | `PingFang SC`, `HarmonyOS Sans SC`, `Noto Sans SC`, `Microsoft YaHei`, system-ui, sans-serif | 正文、按钮、表格、标签 |
| `Mono/码` | `ui-monospace`, `SF Mono`, `JetBrains Mono`, Menlo, Consolas, monospace | **只用于** 6 位核销码与订单号 |

字号阶梯（行高按倍数）：

| 级别 | 字号 / 行高 | 字重 | 用途 |
| --- | --- | --- | --- |
| H1 | 44 / 1.28 | 700 Display | Web 首页主标题 |
| H1-detail | 30 / 1.35 | 700 Display | Web 详情页标题 |
| H2 | 22 / 1.3 | 700 Display | 区块标题 |
| H3 | 16 / 1.45 | 700 Display | 卡片标题 |
| Num-XL | 30 / 1.1 | 700 Display | KPI、Hero 数字 |
| Num-L | 25 / — | 700 Display | 卡片价格 |
| Price-XL | 40 / 1 | 700 Display | 详情页实付价 |
| Body | 15 / 1.65 | 400 | 正文 |
| Body-sm | 14 / 1.6 | 400 | 表格、说明 |
| Caption | 13 / 1.5 | 400 | 次要说明、按钮文字 |
| Tiny | 12 / 1.5 | 400 | Tag、元信息 |

### 3.3 圆角 / 阴影 / 动效

| Token | 值 | 用途 |
| --- | --- | --- |
| `r-sm` | 8px | 小卡片、输入框、图标底 |
| `r` | 12px | 卡片、面板、弹层 |
| `r-lg` | 18px | Modal、大封面、深色区 |
| `r-pill` | 999px | 按钮、Tag、Chip、切换器 |
| `shadow-sm` | `0 1px 2px rgba(18,35,28,.06)` | 切换器选中 |
| `shadow` | `0 6px 18px -8px rgba(18,35,28,.18)` | 卡片 hover |
| `shadow-lg` | `0 24px 60px -24px rgba(18,35,28,.35)` | Modal、Toast、手机外壳 |

动效：时长 `220ms`，曲线 `cubic-bezier(.22,.61,.36,1)`。
页面切换用「淡入 + 上移 8px」；面板切换用淡入淡出或横向滑动；展开折叠用高度 + 透明度。

### 3.4 图标

全部线性图标，**24×24 网格，描边 1.8，圆头圆角连接，无填充**。

底部导航 4 个图标的路径（直接可用）：

```

碳账户 <path d="M4.2 19.8C4.2 11.6 10.4 5.4 19.8 4.2c0 8.2-6.2 15.6-15.6 15.6Z"/><path d="m4.9 19.1 14.9-14.9"/>
```

## 4. 组件库（对应 Axure 的母版）

> 全部建成 Figma Component，页面里用 Instance。变体用 Variant 属性表达。

### C01 Button 按钮
- 属性：`Type` = Primary / Ink / Butter / Ghost / Danger；`Size` = SM / MD / LG；`State` = Default / Hover / Disabled
- 尺寸：SM 高 30 / MD 高 38 / LG 高 46；圆角 pill；左右 padding 16（LG 24）；字号 14（LG 16）
- 配色：Primary `moss` → hover `moss-deep`；Ink `ink` → hover `ink-2`；Butter `butter` + 文字 `ink` → hover `butter-deep`；Ghost 透明 + 边框 `line-strong`；Danger 透明 + `tomato` 文字边框
- Disabled：`opacity 0.45`

### C02 Tag 标签
- 高约 22，padding 2/9，圆角 pill，字号 12
- 变体：Default（`moss-soft` 底 / `moss-deep` 字）· Live 折扣（`butter-soft` / `butter-deep`）· Out 售罄（`rgba(147,160,148,.18)` / `muted`）· Warn 紧张（`tomato-soft` / `tomato`）

### C03 Chip 筛选片
- padding 5/13，圆角 pill，边框 1px `line`，字号 13，`muted`
- 选中：底 `ink`，字 `paper`，边框 `ink`

### C04 Card 卡片
- 底 `card`，边框 1px `line`，圆角 12，无阴影
- Hover（可点时）：`translateY(-3px)` + `shadow` + 边框 `line-strong`

### C05 Meter 进度条
- 高 5，圆角 3，轨道 `rgba(147,160,148,.22)`
- 填充色按语义：**>50% = `moss`；21–50% = `butter-deep`；≤20% = `tomato`**

### C06 BoxCard 盲盒卡片（Web）
- 宽 min 258，自适应；封面区高 124（Emoji 52，渐变底）
- 左上浮 Tag；Body padding 14/16/16，gap 8
- 构成：封面 → 标题 H3 → 档口+取餐时间（12.5 muted）→ 进度条 + 「余 12/40」（12 muted）→ 价格行（现价 25 `tomato` + 原价删除线 13 `muted-2`）

### C07 AppBoxRow 盲盒行（App）
- 全宽 390，padding 14/20，下边框 `line`
- 封面 82×82 圆角 8（Emoji 40）；右侧：标题 15 → 档口+取餐 12 muted → 进度条（宽 70%）→ 价格行 20 `tomato`
- 售罄时封面 `grayscale(.9) opacity(.7)`

### C08 CodeCard 核销码
- 底 `ink`，圆角 12，文字 `paper`
- Web：padding 18/20，码 36px Mono，`butter`，字距 .22em
- App：padding 22 居中，码 **42px** Mono，`butter`，字距 .2em
- 上下各一行 12px `rgba(251,248,241,.65)` 说明

### C09 PanelTabs 面板切换器（动态面板的开关）
- 容器：inline-flex，gap 2，padding 3，底 `rgba(147,160,148,.14)`，圆角 pill
- 按钮：padding 5/16，字号 13，`muted`；选中：底 `card` + `shadow-sm` + `ink` + 字重 500

### C10 Tree 树节点（展开折叠）
- 行 padding 8/10，圆角 8；hover 底 `rgba(147,160,148,.1)`；选中底 `moss-soft` 字 `moss-deep`
- 箭头 16×16，展开时顺时针旋转 90°；子级左边缩进 18
- 右侧可挂行内操作按钮（加子项 / 改名 / 删除），hover 才出现

### C11 Accordion 手风琴
- Head：高约 46，padding 13/2，字号 14；箭头 ▸ 展开旋转 90°
- Body：padding 0/2/14/24，字号 14，`muted`，行高 1.75
- 上分隔线 `line`，每条下分隔线 `line`

### C12 Topbar（Web 顶栏 母版）
- 高 62，sticky 顶部，底 `paper` 92% + 背景模糊 8px，下边框 `line`
- 左：品牌「食光机」22 Display + 副标 12 muted；中：4 个导航 pill（选中底 `ink` 字 `paper`）；右：校区下拉（高 32 pill）+ 头像 30 圆 + 退出

### C13 Tabbar（App 底部导航 母版）
- 高 **58**，4 等分 grid，底 `paper`，上边框 `line`，阴影 `0 -8px 18px -14px rgba(18,35,28,.45)`，下 padding 6
- 每项：图标胶囊 44×26 圆角 13 + 图标 21×21 + 文字 11/1.35 字重 500
- 未选中 `muted`；**选中：图标胶囊底 `moss-soft`，文字 `moss-deep`**（文字不加粗，避免抖动）
- 按下：图标胶囊 `scale(.86)`
- 「订单」项右上可挂 Badge

### C14 AppNav（App 顶部导航 母版）
- 高 48，左右各留 34（返回按钮 / 占位），标题 17 居中，底 `paper` 95% + 模糊

### C15 Side（后台侧栏 母版）
- 宽 232，底 `ink`，sticky，高 100vh
- 品牌区 padding 20/18/16：「食光机」20 Display + 「商家端」徽标（11px，底 `rgba(242,194,48,.16)`，字 `butter`）
- 账号卡：margin 0/14/14，padding 11/12，底 `rgba(255,255,255,.06)`
- 导航项：padding 9/12，圆角 8，`rgba(251,248,241,.78)`；**选中底 `moss` 白字**；图标 18 宽
- 可折叠分组：标题右侧箭头 ▶，展开旋转 90°，子项缩进 14、字号 13

### C16 Toast
- 顶部居中，top 22，底 `ink`，圆角 pill，padding 10/18，字号 14，`paper` 字
- 变体：默认 `ink` / 成功 `moss` / 错误 `tomato`；2.2s 后淡出

### C17 Modal
- 遮罩 `rgba(18,35,28,.42)`；面板宽 440（宽版 620），圆角 18，padding 24，最大高 84vh
- 标题 19；底部右侧按钮组（Ghost「取消」+ Primary「确定」）

### C18 Empty 空状态
- padding 52/20 居中；Emoji 34（灰度 .2）；说明 `muted` 14；下方一个行动按钮

### C19 Table（后台表格）
- 表头：13 `muted`，下边框 `line-strong`，padding 10/12
- 单元格：padding 12，下边框 `line`，14；行 hover 底 `rgba(147,160,148,.07)`
- 数字列用 Display + 等宽数字

### C20 KPI（后台指标卡）
- padding 16/18，边框 `line`，圆角 12，底 `card`
- Label 12.5 `muted` → 数字 30 Display → 脚注 12 `muted-2`
- 变体：普通 / `is-carbon`（数字 `moss`）/ `is-hi`（底 `ink`，数字 `butter`，文字半透明 paper）

### C21 Badge 角标
- 最小宽 16，高 16，圆角 8，底 `tomato`，白字 10 字重 600，边框 1.5 `paper`

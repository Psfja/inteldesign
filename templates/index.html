交互设计课程 · 课后作业一

闭餐前一小时，把食堂没卖完的热菜，半价带回家。

这是一个前后端完整跑通的原型：浏览器里可以真的下单、真的生成核销码、真的在商家后台核销并到账碳积分。 Web 端面向学生，App 端是同一套流程的手机版本，后台面向食堂档口。

作业的四个硬性要求落在哪

工具换成了可运行的代码，但每个原型交互概念都保留了对应实现。

要求实现位置代码片段
动态面板 详情页「里边有什么 / 取餐须知 / 评价」三态切换；后台看板日 / 周 / 月；新建盲盒三步向导；订单与碳账户的 Tab 面板 static/js/core.js → class Panel
母版 三端顶栏、手机底部标签栏、后台侧边导航、盲盒卡片、核销码卡片、Toast、Modal、空状态 Master.define() / Master.render()
展开折叠节点 盲盒广场的餐段树、后台分类树（增删改）、后台侧边导航二级菜单、帮助中心手风琴 bindTree() / bindAccordion()
导航 Web 顶部导航与校区切换、App 底部 4 Tab 与返回栈、后台侧边栏与面包屑、三端互跳 createRouter() / navigate()
两个基本功能 ① 盲盒预订 → 生成核销码 → 后台核销 → 积分到账 ② 碳积分账户：累计、等级、流水、排行榜、兑换 server/api/student.py、server/api/admin.py

技术栈与运行

无构建步骤，装完依赖直接跑。

Python 3 + FlaskSQLite（内置 sqlite3） 原生 ES Module无框架 CSS无前端打包 
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
.venv/bin/python scripts/seed.py --reset   # 建库并写入演示数据
.venv/bin/python app.py                    # 打开 http://localhost:5000

演示账号：学生 18800000001（林小满，已有订单与碳积分）；商家 13900000001（一食堂 · 蒸味档）。 学生端输入任意 11 位手机号会自动注册。
